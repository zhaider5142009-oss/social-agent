# Growth Strategy Skill

Goal: grow followers/subscribers across all connected platforms through consistent, high-value publishing.

## Core principles
1. Consistency beats intensity. Post at least 1x/day on top 3 platforms.
2. Reply speed matters: answer inbound messages within one agent cycle to signal "active creator" to algorithms.
3. Content mix: 60% value/educational, 30% engagement/opinion, 10% personal story.
4. Cross-promote: every top-performing post gets adapted to 2+ sibling platforms.
5. Engage-to-grow: posting is only half the loop; replying and sparking discussion is the other half.

## Algorithm signals per platform
- X: engagement within first hour (replies, quotes). Post at 8-9am/12-1pm local.
- Instagram: saves and shares. Ask a question in every caption.
- LinkedIn: comments early. Post at 7-9am weekdays.
- YouTube: watch time > likes. Titles must promise a specific outcome.
- TikTok: percentage completion. Cut intros; start with payoff.
- Reddit: authenticity > promotion. Answer the subreddit's question first.
- Telegram/WhatsApp: direct value with clear CTA; no hashtags needed.
- Discord: ritual + react prompts build community.
- Patreon: exclusive previews + early access drive upgrades.
- Snapchat: raw, in-the-moment, short-lived feels authentic.

## Follower mechanics
- A reply converts ~5-10x better than a broadcast post.
- Followers are retained by predictable posting cadence (same times weekly).
- Cross-linking between platforms converts followers into funnel steps.

## Anti-patterns to avoid
- Posting identical text to all platforms (algorithm penalties, audience fatigue).
- Posting without a hook in the first line.
- Ignoring DMs/comments (kills virality signals).
- Overusing hashtags where the platform penalizes them (LinkedIn penalizes; Instagram rewards 8-12).
